# Shared implementation contract

Game packs in games/<id>/game.json have {id,title,description,version,plugins,ui?,initial}. initial is {scene,player,entities,scenes,assets,skills,variables,dialogue?}. Entities are {id,name,kind,components}. Components are open records: stats {health,maxHealth,attack,defense,mana,maxMana}, position {x,y,scene}, appearance {glyph,color,asset?}, inventory {items:[]}, equipment {weapon?}, item {heal?,attack?,consumable?}, ai {hostile:true}, interact {action,args}. Scenes contain {id,name,description,map?:string[],exits?:[],choices?:[],background?}. Assets: {id,kind,src,alt?,license?}. Skills: {id,name,cost?,power?,range?,visual?}. Keep game-specific definitions in packs.

Server plugin ESM default export: {id,version,requires?:[],actions:{'namespace.action':{description,input?:JSONSchema,run(ctx,args)}} ,tick?(ctx,deltaMs)}. ctx = {state (mutable transaction draft),session,actor,emit(type,text,data?),random(),require(condition,code,message,hint?)}. Throwing rejects the whole transaction. No side effects inside handlers. Built-in actions are provided by core, combat and narrative plugins. API state is Session {id,gameId,revision,sceneEpoch,seed,state,status,createdAt,updatedAt}. API event {seq,sessionId,revision,type,text,data,at}.

Browser GET /api/games → {games:[{id,title,description,...}]}; GET /api/sessions → {sessions:[...]}; POST /api/sessions {gameId,seed?} → {session, cursor}; GET /api/sessions/:id → {session,cursor}; GET /api/sessions/:id/events?after=N → SSE events named change (payload {session,event}) and ready ({cursor}); POST /api/sessions/:id/actions {action,args,requestId,expectedRevision?,actor:'player'} → {ok,session,events,result,cursor}. Error {ok:false,error:{code,message,hint?,details?}}. Client reconnect fetches snapshot then SSE from snapshot cursor. UI authoring: game.ui points to /games/<id>/ui.js; optional module default export {mount(element,api),update(session),dispose()} factory or function createUI({root,dispatch,asset,escapeHTML}) returning {update(session),dispose?}. Renderer fallback on import/update failure. Never evaluate agent strings.

Core actions: world.move {dx,dy}; world.interact {target}; world.restart not promised; combat.attack {target,skill?}; inventory.use {item}; inventory.equip {item}; narrative.choose {choice}; narrative.say {text}. Narrative scene choices contain {id,label,text?,next?,effects?:[]}; effects DSL applied by shared effects.js: set {path,value}, increment {path,amount}, damage/heal {target,amount}, spawn {entity}, remove {target}, transition {scene}, narrate {text,speaker?}, cue {visual,target?}. Paths are arrays into state, never strings to eval.
