# gen-games

A local-first engine for coding agents to author and run interactive games with real coded UIs. Fast player interactions and rendering remain independent of slower agent turns.

Implementation is in progress. The first version includes a persistent event-driven runtime, bounded incremental agent context, authorable entities and systems, an agent CLI/MCP bridge, and two playable game packs sharing the same engine.

Requires Node.js 24 or newer. No production package dependencies.
